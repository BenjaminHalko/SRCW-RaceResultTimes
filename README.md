# Race Result Times

Shows each racer's time for the race on the results screen.

### Install:

1. Download [UE4SS experimental-latest](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest).
2. Extract the `ue4ss` folder and `dwmapi.dll` into `SonicRacingCrossWorlds\UNION\Binaries\Win64`.
3. Open `ue4ss\UE4SS-settings.ini` and set `MajorVersion` to 5 and `MinorVersion` to 4.
4. Extract the `RaceResultTimes` mod folder into `ue4ss\Mods`.
